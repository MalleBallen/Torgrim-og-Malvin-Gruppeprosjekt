# MOD510 – Project Collection
University of Stavanger

This repository contains four mandatory projects from MOD510, focused on numerical modeling, scientific computing, and applied engineering simulations.

## Project 1 – Numerical Errors & Automatic Differentiation
Explores floating‑point rounding/truncation errors, NumPy vectorization, numerical differentiation (forward/central difference), and implements a simple automatic‑differentiation system using classes and operator overloading.

## Project 2 – Radial Diffusivity & Reservoir Pressure Modeling
Implements steady‑state and time‑dependent solvers for the radial diffusivity equation using finite differences on a logarithmic grid. Includes matrix‑solver comparisons (dense, sparse, Thomas algorithm) and matching numerical results to real well‑test data.

## Project 3 – ODE Solvers & Aorta Modeling
Implements Euler, RK2, and RK4 solvers and uses CSTR (n‑tank) models to approximate CFD tracer simulations in an aorta. Includes parameter fitting and comparison between healthy and aneurysm cases.

## Project 4 – Stochastic Modeling & Random Walks
Models mixing tanks with Monte Carlo simulations and uncertainty quantification. Extends to 2D random‑walk modeling of contaminant transport, arrival‑time statistics, and biased vs unbiased spreading.
